Covernas 使用说明

      
Covernas 家庭服务器 V1.0 · 开发者 XCR。一台玩客云（ARMv7 / 1GB 内存 / 8GB eMMC）运行的自研 NAS 面板：文件、相册、媒体、下载、备份、建站一站式管理。


      
快速上手

      
    
        
  • 面板入口：浏览器打开 http://设备IP（默认 80 端口），首次使用请先在「设置 → 修改密码」改掉初始密码。
    • 
        
  • 手机访问：手机连同一 WiFi，打开「设置 → 手机访问」扫二维码直达；页面已适配手机屏幕。
    • 
        
  • 传文件：「我的存储」点「上传」或直接把文件拖进页面；支持多选、复制/剪切/粘贴、压缩解压、分享链接。
    • 
        
  • 看照片看视频：「相册」自动扫描 /mnt 里的图片，「媒体播放」播视频（记住进度、倍速），「音乐」播音频。
    • 
      


      
数据放哪里

      
    
        
  • 所有个人数据放 /mnt（外接盘）；删掉的文件进回收站（/mnt/.trash），可随时找回或清空。
    • 
        
  • 系统目录受保护：/etc、/usr 等系统路径在面板里只读，防止误删系统文件。
    • 
        
  • 下载类软件默认目录：/mnt/downloads；网站文件放 /mnt/www。
    • 
      


      
局域网共享

      
    
        
  • Windows/Mac：访达/资源管理器访问 smb://设备IP，账号密码在「网络共享 → SMB」里管理。
    • 
        
  • NFS / FTP / WebDAV：在「网络共享」里按需开启，适合机顶盒、电视、备份软件对接。
    • 
      


      
下载与远程

      
    
        
  • Aria2 下载中心：面板「下载中心」入口，HTTP/磁力/种子都行。
    • 
        
  • BT 下载：Transmission（:9091），PT 做种友好。
    • 
        
  • 出门在外：「远程访问」里配置 Tailscale（推荐）或 frp 内网穿透，不建议直接把端口暴露到公网。
    • 
      


      
维护与故障

      
    
        
  • 服务启停/日志：「后端服务」；进程占用：「任务管理器」；磁盘健康：「系统维护 → 磁盘健康（SMART）」。
    • 
        
  • 面板日志：「设置 → 面板日志」；面板异常可「设置 → 重启面板」，不影响其他服务。
    • 
        
  • 忘记密码：SSH 登录后查看 /etc/box/recovery-key，在登录页「忘记密码」用恢复码重置。
    • 
        
  • SSH：ssh root@设备IP。终端 banner 输入 tips 有命令提示。
    • 
      


      
这台机器的底线

      
    
        
  • 1GB 内存：常驻服务别贪多，Java/数据库/转码跑不动。
    • 
        
  • 8GB eMMC：系统只占一小半，但日志和缓存要定期清（「系统维护 → 系统清理」）。
    • 
        
  • ARMv7 + USB2.0：装软件认准 armhf 包；硬盘实际读写约 35MB/s。
    • 
      


      
备份

      
面板代码在 /opt/box，配置在 /etc/box，整机备份在 /root/box-backup-*。数据备份用「磁盘备份」做 rsync 定时同步到外接盘。
